Обоснование начальной (максимальной) цены договора

Сервис по техническому заданию находит цены сопоставимых товаров в реестре контрактов ЕИС и на сайтах поставщиков, сверяет их с требованиями ТЗ и готовит обоснование методом сопоставимых рыночных цен (статья 22 Федерального закона № 44-ФЗ, приказ Минэкономразвития России № 567).

Запуск

Нужен Docker с Compose v2. Сервис поднимается одной командой и открывается в браузере по адресу http://localhost:8000.

git clone {{ repo_url }}
cd nmcd-analyst
docker compose up -d --build

Без ключей сервис разбирает ТЗ по правилам и берёт цены из реестра контрактов ЕИС. Ключ поискового API добавляет цены интернет-магазинов и дистрибьюторов, ключ модели — разбор ТЗ и страниц моделью; ключи записываются в файл .env по образцу .env.example. Общедоступный стенд с HTTPS поднимается командой из deploy/README.md.

Как устроен расчёт

  1. Из ТЗ составляется карточка: позиции, количество, существенные характеристики с цитатами.
  2. Цены ищутся в исполненных контрактах ЕИС и на сайтах поставщиков; у каждой цены — ссылка, дата и копия страницы.
  3. Каждая характеристика предложения сверяется с ТЗ; другая модель, совместимый товар или неподтверждённая характеристика — причина исключения.
  4. Цена приводится к единице закупки: фасовка, НДС, доставка, индекс потребительских цен для цен старше полугода.
  5. Проверяются неустойки по контракту и реестр недобросовестных поставщиков, исключаются выбросы, считается коэффициент вариации.
  6. Если цен не меньше трёх и разброс не выше 33 %, НМЦД равна количеству, умноженному на среднее арифметическое; иначе сервис готовит запрос коммерческих предложений.
