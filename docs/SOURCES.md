# Источники ценовой информации

Источники из перечня организаторов проверены на возможность программного доступа без обхода защиты
(robots.txt и пробный запрос, 11.11.2026). Правило сервиса: если сайт запрещает программный доступ или отвечает
антибот-проверкой, он не используется, и это видно в отчёте.

| Источник | Что даёт | Доступ | Используется |
|---|---|---|---|
| ЕИС, реестр контрактов 44-ФЗ (zakupki.gov.ru) | Исполненные контракты: позиции, цена за единицу, количество, КТРУ/ОКПД2, характеристики, поставщик и ИНН, дата заключения | robots.txt не ограничивает; страницы открыты; нужен корневой сертификат Минцифры (входит в образ) | Да, основной источник (ч. 18 ст. 22 44-ФЗ) |
| Сайты поставщиков и интернет-магазины | Публичные цены и характеристики товаров | Поиск через Яндекс Search API v2 (официальный платный API), страницы загружаются с учётом robots.txt | Да, если задан ключ поискового API |
| ЕАТ «Берёзка» (agregatoreat.ru) | Оферты малых закупок | На запрос программы отвечает страницей-заглушкой антибота | Нет, обход защиты не выполняется |
| Портал поставщиков Москвы (zakupki.mos.ru) | Оферты и контракты | Данные отдаются через `/api`, который запрещён в robots.txt | Нет |
| ГИСП (gisp.gov.ru) | Каталог промышленной продукции | Отвечает 403 на запросы программ | Нет |
| ВсеИнструменты, Ozon, Wildberries, Яндекс Маркет | Розничные цены | Антибот-защита или запрет в robots.txt | Нет |
| Интернет-магазины и дистрибьюторы (найденные поиском) | Карточки товаров: цена, характеристики из таблиц | Каждая страница загружается, только если её путь разрешён robots.txt | Да, карточки находятся через поисковый API |
| Комус | Карточки товаров | На 12.11.2026 robots.txt закрывает карточки для программ | Нет |
| Федеральные ЭТП (Сбербанк-АСТ, РТС-тендер, Росэлторг и др.) | Процедуры закупок | Сведения о заключённых контрактах дублируют ЕИС | Нет, используется ЕИС |
| Росстат, индексы потребительских цен | Приведение старых цен к текущему уровню (п. 3.14, 3.18) | Официальный файл `ipc_mes_*.xlsx` с rosstat.gov.ru | Да, ряд в `data/cpi_rosstat.csv`, обновление `tools/update_cpi.py` |

Список доменов, которые не запрашиваются, — `config/sources.yaml` (`blocked_domains`, `skip_domains`).
Новый источник подключается модулем в `app/sources/` с тем же интерфейсом и включается в `config/sources.yaml`.
